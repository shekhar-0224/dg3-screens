01Chart / Stream Tab Strip

A 36px strip above the chart and stream zones. Two tabs: CHART (default) and LIVE. Controls live on the right side and are scoped to the active tab.

Tab anatomy

Height
36px. Background var(--bg2). 1px bottom border.
Font
JetBrains Mono 10px/800, 0.1em letter-spacing, uppercase.
Active state
var(--t1) text, 2px gold bottom border.
Inactive state
var(--t3) text. No border.
Default
CHART tab is active on load.

CHART tab controls (right side)

Outcome filter
"ALL OUTCOMES" dropdown. Filters which price series render. Options are the outcome labels from the current market.
Timeframe picker
Gold pill showing active TF (default 15M). Click opens dropdown. Groups: In-Play (5M · 15M · 30M), Session (1H · 3H · 12H · ALL).
Pop-out button
Square-with-arrow icon. Detaches chart into a draggable, resizable floating panel. Clicking again docks back.

LIVE tab controls (right side)

Channel dropdown
Platform icon (YouTube / Twitch / Kick) + label + viewer count + active checkmark. Only shown when ipCsSetChannels(sources) has been called with at least one source.
Pop-out button
Same icon as chart. Only visible when LIVE tab is active. Detaches stream into a floating panel with the channel dropdown inside.
Tab label: no source
Circle-play icon + "STREAM" label in var(--t3).
Tab label: source active
Red pulsing dot (6px) + "LIVE" label in var(--t1). Icon hidden.

02Chart — Changes

Full chart spec is in the Intelligence Pane PRD. This section covers only what changed.

Timeframe dropdown

Old
Inline buttons: 1H · 3H · 1D · 7D · ALL.
New
Gold pill dropdown showing active TF. Click opens menu. Options: 5M · 15M · 30M · 1H · 3H · 12H · ALL. Default active: 15M. Same dropdown appears in both the inline tab strip and the chart pop-out header.
Active indicator
Gold dot to the right of the active option label inside the menu.

Legend labels

Old
Small inline text labels: "Polymarket" and "Sharp Line".
New
Bordered pill buttons with line swatch inside. Labels: POLYMARKET LINE (solid swatch) and FAIR PRICE (dashed swatch). Active state: gold-tinted border + subtle gold fill. Inactive: 45% opacity, plain border. Click toggles series visibility. At least one must remain active.

03Stream (Live)

Live video feed from Twitch, YouTube, or Kick. Only shown when LIVE tab is active. Height matches chart zone.

Phase 0 limitation
YouTube embeds may show Error 153 in local file:// context due to iframe origin restrictions. In production on HTTPS these resolve correctly.

Zone

Height
310px. Matches chart zone. Background #080808.
No source state
Centered platform icon + "Live Stream" heading + "Select a channel above to start watching" sub-label.
Active source
16:9 iframe fills zone. ● LIVE badge overlays top-left corner.
Tab switch pause
When switching away from LIVE tab, iframe.src = iframe.src is reassigned to pause audio.

Pop-out panel

Default size
720×420px. Centered on viewport.
Draggable
By header. Same grab cursor behavior as chart popout.
Resizable
Bottom-right handle. Min 400×250px.
Header
Stream icon + platform label + "· Live" + channel dropdown (same as tab strip) + close (×) button.
Close
× button in header, or clicking the pop-out button again. DOM node is removed.
No source
"NO STREAM SOURCE" centered message in var(--t4) mono.
Channel order
Channels are displayed in the order supplied by ipCsSetChannels(sources). Production data pipeline should pass sources in priority order: Twitch first, Kick second, YouTube third — or whatever is highest quality for the fixture. The first channel in the array is the default active source. No UI sorting is applied.

05Positions

Shows the trader's open positions. Fixture-relevant positions appear first, followed by other matches on expand.

Sub-tabs

Items
Positions (with count badge) / Orders. Slash separator.
Height
28px. Same styling as bottom strip but smaller: 8px/700, gold on active, var(--t2) on inactive.

Position row (live deck)

Anatomy
Left accent bar
2px. Green for positive P&L, red for negative P&L.
Line 1
Market name (12px/800, var(--t1)) + outcome pill inline. Pill: green bordered for YES direction, red bordered for NO direction. 8px mono.
Line 2
@ [entry]¢ · [N] shares · $[cost]. 10px mono, var(--t3).
Right — P&L
12px/800. Green if positive, red if negative.
Right — price arrow
52¢ → 55¢. 9px mono, var(--t3). Entry → current price.
Padding
10px top/bottom, 14px right, 12px left of accent bar.
Hover
rgba(255,255,255,.03) background.

Position row (resolved / post-match deck)

Layout
Same as live row. Read-only — no interaction.
Price arrow
Entry → settlement price. Settlement colored green (99¢) or red (0¢). SETTLED micro-badge appended (6px mono, bordered).

Other positions

Placement
Below fixture positions. No section header for fixture rows — they appear first with no label.
Divider
Horizontal rule with + Other positions (N) centered in it. Always visible when other positions exist.
Expand
Click divider to expand. Icon changes + → −. Click again to collapse. All in the same scroll container — no separate scroll zone.

Empty state

Label
NO OPEN POSITIONS. 8px mono, var(--t4), uppercase. Centered in pane.

06Orders

Open limit orders grouped under the same sub-tab strip as Positions. Shown on switching to the Orders sub-tab.

Order row

Anatomy
Left accent bar
2px. Gold (rgba(205,189,112,.4)) for all pending/partial orders.
Line 1
Market name + outcome pill (same chip style as positions) + limit price in gold (@ 58¢, 11px/700) + status badge right-aligned.
Status badge
PENDING: muted background, var(--t3). PARTIAL: gold-bordered, var(--g3).
Fill bar
2px track. Gold fill at fill percentage. 0% for Pending; partial % for Partial fills.
Fill line
$[filled] of $[total] filled · [N] shares · GTC/GTD [· Exp date]. 9px mono, var(--t3).
No cancel action in Phase 0
Order rows are read-only in Phase 0. Cancel and modify actions are deferred to Phase 1.

Empty state

Label
NO OPEN ORDERS. Centered. Same treatment as positions empty state.

07Chat

Event discussion channel. Coming soon. Kept in the tab strip to communicate the roadmap.

Height
Fixed 120px. flex:none. Does not expand to fill remaining space.
Content
Blurred event brief and placeholder messages at 5px blur, 35% opacity.
Overlay badge

08Resolved Deck Rules

When the active deck is resolved or post-match, the bottom section enforces specific UI rules on every render.

Detection
Trigger flags
deck.resolved, deck.resolvedState, or deck.postMatch being truthy. Also checked via ipDeckId.indexOf('post') as fallback.
CSS class
body.deck-resolved is set by the IIFE at the end of every ipFullUpdate(). This is the single source of truth for hiding elements on resolved decks.
Bottom section changes
Positions tab
Shows settled position rows. Settlement price (99¢ or 0¢) colored by outcome. SETTLED badge. Read-only.
Orders tab
Empty state. No pending orders on a closed market.
Place Trade CTA
Label changes to "Market Resolved". Button disabled.
Restore on live deck
body.deck-resolved class is removed by the IIFE when the active deck is not resolved. Bottom section returns to normal state.

11Tailwind Token Mapping

Drop this into tailwind.config.js to use DG3 design tokens as Tailwind utilities. After this, use bg-bg1, text-t1, border-line2 etc. directly in class names.

This is a config extension, not a replacement
This extends Tailwind's default theme — all standard Tailwind utilities still work alongside these. The file uses vanilla CSS variables internally; this mapping lets you consume those same tokens from Tailwind class names in React/Vue components built on top of the terminal.
